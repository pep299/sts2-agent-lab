# イベント接続の現在地

更新: 2026-10-26。対象ブランチ: codex/event-coverage。

全ラン勝率を改善する実験をイベント由来の接続エラーで止めないため、ソロIronclad・A0・v0.111の登録65件とTheArchitectを調査・修正した。基本走査、条件付き候補、Ancientの子選択・報酬連鎖を両環境で検査した。実装・検証範囲・根拠は[event-coverage-20261024.md](event-coverage-20261024.md)。

- Cloneの公開親文脈、任意取得、カード束の未接続を修正。任意取得・束・CLAWSには明示した代理/固定方策を使用する。
- 現PPOは対象版向け未学習。重みは変更しておらず、判断品質・全ラン勝率は未評価。
- 通常ショップ限定の取得時選択5種を接続し、両環境で実購入・子選択・効果適用を確認。learnでは子選択後も購入Taskを保持し、効果・在庫消費の完了まで待つ修正を加えた。
- Crystalは公開セルの画像片と固定10種の画像辞書を接続。Mentorは部分画像から確定できた矩形だけを使い、呪いの完成回避・報酬の完成を優先する。曖昧な画像は不明のまま扱う。全状態組合せ・スクリーンショット一般認識の検証ではない。
- 変更はこのブランチとlearnのローカルコミットに限定。mainへ未統合、未push、PRなし。生ログはGit対象外。
- 専用アプリは通常版modへ復旧済み。新ブランチのnative検査には同ブランチのnative-buildが必要。
