# ChatでMentorを使う

## 新規開始

`mentor-chat` artifactの取得先を渡して、次を指示する。

```text
このartifactを取得・展開し、START_HERE.mdに従ってMentorでランを開始して。
v0.113.0、アイアンクラッド、A10、seedは7。
まずマップとエンシェントの全選択肢を見せて止めて。
要求版が未対応なら、別版で進めずエラーを報告して。
```

取得できない場合はartifact ZIPをチャットへ添付し、同じ指示を使う。v0.111の動作確認をする場合は、要求版を明示的に`v0.111.0`へ変更する。

## 再開

開始時と同じartifact ZIPと、採用中の保存JSONを渡す。

```text
artifact内のSTART_HERE.mdに従い、添付の保存JSONをSession.loadで再開して。
現在地、HP、デッキ、レリック、ポーション、現在の選択肢を示して止めて。
```

## 進行中の指示例

- 「列5のルートで。次の戦闘まで進めて。ポーションは使わずに」
- 「T1で右にBash、防御に変えて比較して。元の分岐は残して」
- 「比較した方を採用して、次のイベントまで」

保存JSONだけでは、元の実行ファイルが消えた場合に再開できない。**artifact ZIPと保存JSONを両方保管する。**
