# Native headless

macOS上の実ゲームを操作する。設定例を`config/native-headless.local.toml`へコピーし、利用するアプリ・progress・設定を指定する。入力から専用コピーを作り、通常プレイのインストールへは書き込まない。

実ゲームの回帰試験にはローカルの参照ログと保存局面が必要で、これらは配布しない。入力がない環境では、ゲーム不要の試験が成功しても実ゲームを検証したことにはならない。

環境エラー・中断・保存再開の勝利を、自然全ランの勝利教師に混ぜない。分岐再生は同じ開始条件のグループとして扱い、独立標本として数えない。

上流コードの扱いは[NOTICE.md](../../NOTICE.md)を参照。
